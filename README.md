# monitoring-class
Sistem Monitoring Kehadiran Berbasis IoT - Proyek ini memantau kehadiran siswa dan guru secara otomatis menggunakan Bluetooth Tag, ESP32, dan LoRa. Data dikirim ke aplikasi web Laravel melalui API, lalu diolah menjadi laporan. Notifikasi kehadiran dikirim ke WhatsApp orang tua dan Wakil Kepala Kurikulum.
